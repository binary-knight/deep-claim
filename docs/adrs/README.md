# Architecture Decision Records

One file per decision: `NNN-slug.md`, numbered in the order decided, with
Context, Decision and Consequences. Written by `/architect` or by hand.

Decisions made before 2026-10-10 are in `docs/DESIGN.md` (an append-only
log) and are not back-filled here. The ratified rules that came out of them
are in `ARCHITECTURE.md`.
