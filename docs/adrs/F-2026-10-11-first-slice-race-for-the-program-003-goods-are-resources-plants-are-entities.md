# ADR-F-2026-10-11-first-slice-race-for-the-program-003: Products are resources; a plant is a new entity that moves stock

**Date:** 2026-10-11
**Status:** Accepted
**Context:** Step 2 adds steel and launch structures and the plants that make them (spec BR-015 to BR-019). Products need stock, a market, a price, sell policies, storage and deliveries, all of which exist per resource. Plants have no counterpart today.
**Decision:** Products join the ores in `data/resources.json`, each resource carrying a kind (ore or product). A product never occurs in a deposit and has no mine running cost. Plant types are defined in a new `data/plants.json` (inputs and outputs per day, build cost and time, running cost). A plant is a saved entity with an owner, a type, a region and a state, built by order without a plot. A new plants step runs after the mines step and before sell policies: each running plant draws its inputs from company stock and adds its outputs, in proportion when inputs are short, in whole tonnes. Program requirements name resources, so step 1's deliveries need no change when products arrive.
**Consequences:** Everything that works for an ore works for a product with no second code path, and the market code is unchanged. Code that assumed every resource is dug (survey estimates, running-cost rules, the AI's valuation) must check the kind; the loader enforces that products have no deposit entries. Plants add a step to the fixed tick order, which is recorded in `docs/DESIGN.md`. This record covers step 2 and is re-read with the owner after the step-1 playtest before that step is built.
