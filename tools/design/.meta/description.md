# design

**Purpose:** Two standalone Python generators that produce committed UI assets for the RmlUi game client: the design-token lookup stylesheet `game/assets/ui/tokens.rcss` and the navigation-rail icon sprite sheet `game/assets/ui/icons.tga`. Both are run by hand from the command line; neither is invoked by CMake or CI.

## Key Components
- `tokens_to_rcss.py` (92 lines) - `tokens_to_rcss.py <tokens.css> <tokens.rcss>`. `parse()` matches lines of the form `--name: value; /* note */` with `TOKEN_RE`; `render()` emits a header comment that begins `GENERATED by tools/design/tokens_to_rcss.py` and lists every token name, value and note in a padded table, followed by utility classes: `.c-<name>` and `.bg-<name>` for every 6-digit hex value, `.f-<face>` for `font-*` tokens (first family in the list, quoted, via `font_family()`), and `.fs-<n>` for `fs-*` px tokens with `line-height` taken from the matching `lh-<n>` token (falls back to the font size). Exit codes: 2 on wrong argument count (prints the docstring), 1 when no tokens are found, 0 on success.
- `icons.py` (131 lines) - `icons.py <icons.tga>`. Draws seven 24x24 line icons in the fixed order of `ICONS` (`dashboard`, `plots`, `market`, `research`, `finance`, `log`, `program`; `program`, a rocket on its pad, was added for spec 010's Program tab) with a small software rasterizer (`Canvas.line`, `rect`, `polyline`, `downsample`; distance-to-segment coverage at 4x supersampling, 2px strokes) and `write_tga()` writes them side by side as one 168x24 uncompressed 32-bit TGA, white with alpha coverage, top-left origin. Takes no input file; the geometry is hard-coded in `draw()`. Exit codes: 2 on wrong argument count, 0 on success.

## Dependencies
- Python 3 standard library only: `re`, `sys`, `pathlib` (`tokens_to_rcss.py`); `math`, `struct`, `sys`, `pathlib` (`icons.py`). No third-party imports, no subprocesses, no network access.
- Uses `str.removeprefix` / `str.removesuffix`, so `tokens_to_rcss.py` needs Python 3.9 or later.
- Reads `docs/design/tokens.css` (the documented argument to `tokens_to_rcss.py`).
- Writes into `game/assets/ui/`: `tokens.rcss` and `icons.tga` (the documented arguments; the scripts write to whatever path is passed).
- Incoming: `tests/design_tokens_test.cpp` (Catch2, part of `sim_tests`) reads `docs/design/tokens.css` and `game/assets/ui/tokens.rcss`, checks the `GENERATED by tools/design/tokens_to_rcss.py` marker, checks that every token name and value appears in the table, and checks four specific utility-class lines. `game/assets/ui/main.rcss` references `icons.tga` through `@spritesheet icons`. The scripts themselves are not referenced by any `CMakeLists.txt` or by `.github/workflows/ci.yml`.

## Patterns
- Python: single-file CLI scripts with a `#!/usr/bin/env python3` shebang, a module docstring that doubles as the usage message, `from __future__ import annotations`, type hints, and `main(argv) -> int` wrapped in `sys.exit(main(sys.argv))`.
- Generated-and-committed assets: the output files are checked in and carry (for `tokens.rcss`) a do-not-edit header; a C++ test, not the build, detects a stale `tokens.rcss`.
- No image library: `icons.py` builds the TGA header with `struct.pack` and writes BGRA bytes directly.
- Design-token mirroring: RmlUi has no CSS custom properties, so `main.rcss` uses literal values and `tokens.rcss` serves as the name-to-value reference table plus utility classes.

## Constraints
- `tokens_to_rcss.py` recognises only one token declaration per line, with lowercase names matching `[a-z0-9-]+`; colour classes are emitted only for values that are exactly `#rrggbb` (no 3-digit, 8-digit, `rgb()` or named colours).
- Font sizes are converted from CSS `px` to RmlUi `dp` units; non-`px` `fs-*` / `lh-*` tokens get no utility class.
- The header text emitted by `render()` is asserted verbatim by `tests/design_tokens_test.cpp`, as are `.c-text`, `.bg-canvas`, `.f-num` and `.fs-14` output lines.
- `icons.py` icon order and the 24px cell size fix the sprite coordinates that `game/assets/ui/main.rcss` maps in its `@spritesheet` (`icon-dashboard` at 0px through `icon-program` at 144px); an unknown icon name yields an empty cell.
- No test covers `icons.py` or the content of `icons.tga`.
- Both scripts carry a `python3` shebang and are tracked with git mode 100644 (not executable).
