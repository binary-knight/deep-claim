# backends

**Purpose:** RmlUi's reference SDL + OpenGL 3 backend, vendored as source and compiled into the static library `rmlui_backend`. It opens the SDL window and GL context, feeds SDL events to an RmlUi context and renders RmlUi geometry with OpenGL 3.3.

## Key Components
- `RmlUi_Backend.h` - The `Backend` namespace API used by the client: `Initialize`, `Shutdown`, `GetSystemInterface`, `GetRenderInterface`, `ProcessEvents` (with a `KeyDownCallback`), `RequestExit`, `BeginFrame`, `PresentFrame`, plus the Deep Claim addition `SetPreSwapCallback`.
- `RmlUi_Backend_SDL_GL3.cpp` - Implementation of that API for SDL + GL3. In-file comments mark two Deep Claim changes: the SDL_image texture loader is removed (textures load through `RenderInterface_GL3`'s TGA loader) and a pre-swap callback is invoked in `PresentFrame`; the comment states "No other changes".
- `RmlUi_Platform_SDL.h` / `RmlUi_Platform_SDL.cpp` - `SystemInterface_SDL` (time, cursors, clipboard, on-screen keyboard) and the `RmlSDL` helpers that translate SDL events, keys and modifiers for RmlUi. Supports SDL 2 and 3, selected by `RMLUI_SDL_VERSION_MAJOR`.
- `RmlUi_Renderer_GL3.h` / `RmlUi_Renderer_GL3.cpp` - `RenderInterface_GL3`, the `Rml::RenderInterface` implementation (geometry, textures, clipping, layers, filters, shaders).
- `RmlUi_Include_GL3.h` - Header-only OpenGL 3.3 core loader; its header says "Loader generated by glad 2.0.0-beta on Fri Mar 11 10:53:06 2022" and it embeds the Khronos `khrplatform.h` notice.
- `LICENSE-RmlUi.txt` - MIT licence, "Copyright (c) 2008-2014 CodePoint Ltd, Shift Technology Ltd, and contributors" and "Copyright (c) 2019-2026 The RmlUi Team, and contributors".
- `.clang-format` - `DisableFormat: true`, `SortIncludes: Never`.

## Dependencies
- `RmlUi::RmlUi` and `SDL3::SDL3` (PUBLIC links of `rmlui_backend` in `game/CMakeLists.txt`); OpenGL through the bundled glad loader.
- Used by `game/src/main.cpp` (`RmlUi_Backend.h`) and `game/src/screenshot.cpp` (`RmlUi_Include_GL3.h` for `glReadPixels`), which reach the headers through the target's PUBLIC include directory.
- No dependency on `sim`, `content`, `platform` or `game/session`.

## Patterns
- Third-party sample code kept verbatim apart from marked edits; provenance as stated in `game/CMakeLists.txt`: "vendored from the RmlUi 6.3 source tree (MIT, see backends/LICENSE-RmlUi.txt)".
- Local changes are flagged with comments beginning `Deep Claim:` or `Deep Claim addition:`.
- Plain function-pointer callbacks (`KeyDownCallback`, `PreSwapCallback`) and file-static backend state whose lifetime runs from `Backend::Initialize` to `Backend::Shutdown`.

## Constraints
- Compiled with all warnings off (`-w`, or `/w` on MSVC) and with `RMLUI_SDL_VERSION_MAJOR=3`.
- Excluded from formatting (local `.clang-format` and the `grep -v '^game/backends/'` in the CI clang-format job in `.github/workflows/ci.yml`) and not matched by the `HeaderFilterRegex` in `.clang-tidy`.
- Built only when the parent `game/CMakeLists.txt` is included, that is with `DC_BUILD_GAME=ON`.
- Only uncompressed TGA textures load, because the SDL_image loader was removed.
- `PreSwapCallback` runs after the frame is drawn to the default framebuffer and before the buffer swap; `game/src/screenshot.cpp` relies on that ordering.
