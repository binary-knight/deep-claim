# sim_runner

**Purpose:** Headless balance-run executable (`sim_runner`). It builds a `sim::Simulation` from the JSON content in `data/`, drives every company (the player's slot included) with `sim::HeuristicController` until the game ends (spec 010: a company founds the program, or the deadline passes) or the requested days run out, and prints a JSON report on stdout, optionally a CSV file, with an exit code that encodes whether the checks passed. It has two modes: a single-seed run (optionally gated by `--sanity`) and a multi-seed `--sweep N` that measures the spec 005 (world and opening), spec 006 (balance), spec 008 (markets that bite) and spec 010 (the race for the program) goals.

## Key Components
- `CMakeLists.txt` -- defines the `sim_runner` executable from `main.cpp`, links `dc::sim`, `dc::content`, `dc_warnings`, sets the compile definition `DC_DATA_DIR="${CMAKE_SOURCE_DIR}/data"`, and registers four CTest tests:
  - `runner_smoke`: `sim_runner --seed 1 --years 5 --ai 1 --sanity`, judged by its exit code.
  - `runner_outcome`: `sim_runner --seed 1 --years 2 --ai 1 --sanity`, judged by a `PASS_REGULAR_EXPRESSION` (outcome `running`, founder -1, `founded_day`/`never_day` 721, `stage_days` list, `all_passed` true).
  - `runner_sweep`, in one of two variants chosen at configure time. When `CMAKE_BUILD_TYPE` is in `DC_OPTIMIZED_BUILD_TYPES` (Release, RelWithDebInfo, MinSizeRel) and `DC_SANITIZE` is off: `sim_runner --sweep 50 --years 30 --ai 1 --sanity`, judged by its exit code, `TIMEOUT 180`, with a `FAIL_REGULAR_EXPRESSION` that fails on a gated check reporting "not evaluated". Otherwise: `sim_runner --sweep ${DC_SHORT_SWEEP_SEEDS} --years 30 --ai 1` (1 seed under `DC_SANITIZE`, else 2), `TIMEOUT 300`, judged by a long `PASS_REGULAR_EXPRESSION` over the row race fields, the race summary and every check name and gating, with a `FAIL_REGULAR_EXPRESSION` on `Sanitizer`, `runtime error:` or an outcome of `running`.
  - `runner_bite_measures`: `sim_runner --sweep 2 --years 3 --ai 1 --sanity`, judged by a `PASS_REGULAR_EXPRESSION` (idle-run fields, running outcomes with never day 1081, null year-10/20 figures, race checks and spec 008 checks "not evaluated", `all_gated_passed` true).
- `main.cpp` -- the whole program (1785 lines, everything except `main` in an anonymous namespace). Parts, in file order:
  - Game end (spec 010): `Options` (with `tickLimit`), `tickLimitFor` (one extra tick when `--days` equals `Content::program.deadlineDay`, so a run to the deadline gets its outcome), `neverDay` (`tickLimit + 1`), `keepPlaying`, `RunOutcome` (`Running`/`Founded`/`Deadline`), `outcomeOf`, `outcomeName`, `endDayOf`, `founderIndex`, `dayOrNever`, `noStageDays`, `recordStageDays` (from `ProgramStageComplete` notices), `countsAgainstAi` (excludes `RejectReason::GameEnded`), `joined`, `stageDaysJson`.
  - Argument parsing: `parseUnsigned`, `parseNumericOption`, `parseArgs`. Flags: `--seed N`, `--days N`, `--years N`, `--ai N`, `--data DIR`, `--csv FILE`, `--sanity`, `--sweep N`.
  - Single run: `saturatingAdd`, `MarketStats`/`RunStats`/`Check`, `jsonString`, `writeCsvHeader`/`writeCsvRows` (one row per company at each month end), `recordDay` (per-market min/max/sum price and days at floor/cap, rejected-command counts by `sim::rejectReasonName`, rejections counted against the AI, stage days, bankruptcy day, first-mine day, peak cash, peak debt, yearly `sim::validateWorld` failures; skips the tick that ends the game), `run` (per day: `Simulation::collectCommands` for each company, then `Simulation::tick`), `buildChecks` (five checks: `world_valid`, `no_runaway_money`, `prices_sane`, `ai_commands_valid`, `economy_alive`), `printSummary` (JSON).
  - Sweep: goal constants (spec 005, 006, 010 race, 008 bite), `SweepRow` (per-seed figures plus working state), `describeQueue` (opening hand classified with `sim::classifyRegionAtStart`, longest same-region run in the listing queue), `recordFirstMine`, `recordLand`, `recordContest`, `meanPermille`, `finishContest`, `belowBaseBreakEven`, `recordBitePrices`, `recordBiteCompanies`, `biteDaysCovered`, `finishBite`, `sweepSeed` (plays one seed until its game ends or the days run out), `yearSampled`/`sampleList`, `Spread`/`spreadOf`/`spreadOver` (min, lower median, max), `Sample`/`sampleOver` (spread over the seeds that reached a point, and their count), `reachedGoalYear`/`reachedCashYear`, `spreadJson`, `minesAtEnd`, `kNoContestPercent`, `minesRatioPercent`, `anyBankrupt`, `pooledMineLives`, `contestJson`, `biteMeasured`/`priceYearsMeasured`/`cashY10Measured`/`laterYearsMeasured`/`biteGatesApply`, `listOrNull`, `biteJson`, `foundedDay`/`isFounded`/`winsByCompany`, `raceJson`, `bankruptWithin`/`bankruptEarly`/`bankruptLater`/`hasIdledMine`, `writeContestCsv`/`writeRaceCsv`/`writeSweepCsv`, `noSeedReached`, `sweepChecks`, `raceChecks`, `contestChecks`, `biteChecks`, `printSweepRows`, `printSampleLine`, `always`, `printBiteSummary`, `printRaceSummary`, `printContestSummary`, `printSweep`, `runSweep`.
  - `main` -- parses args, loads content with `content::loadFromDirectory`, sets `tickLimit`, dispatches to `runSweep` or the single run.

## Patterns
- Single translation unit, free functions in an anonymous namespace, no classes with behavior; plain structs (`Options`, `RunStats`, `MarketStats`, `Check`, `SweepRow`, `Spread`, `Sample`) carry state between the phases parse -> simulate -> record -> check -> print.
- All companies are AI-driven with one shared `sim::HeuristicController`; company 0 is the player's slot, named "Player (AI)", rivals are "Rival 1..N" (`--ai N`).
- A run never ticks a finished world: the loop stops when `sim::gameEnded` or the tick limit is reached. The tick that ends the game closes no day, so its per-day samples (prices, cash, land, contest, bite, CSV rows) are skipped; only its notices (stage days, rejections) are recorded.
- JSON is hand-written with `std::format` to stdout (no JSON library); CSV goes to the `--csv` file. Money is printed with `sim::toString`. Days in the output are 1-based; a day that never came prints as `never_day`.
- Single-run JSON top-level keys: `seed`, `days`, `state_hash`, `outcome`, `founder`, `founded_day`, `end_day`, `never_day`, `companies` (each with `program_stage` and `stage_days` among its fields), `markets`, `rejections`, `checks`, `all_passed`. Single-run CSV columns: `day,company,cash,debt,plots,mines_operating,mines_mothballed,mines_depleted,inventory_value` then one `price_<resource id>` per resource.
- Sweep JSON top-level keys: `sweep` (`first_seed`, `seeds`, `days`, `ai`, `deadline_day`), `rows` (one object per seed: opening and land fields, contest fields, spec 008 fields such as `below_breakeven_permille`, `mine_days_idled`, `cash_y10`, `longest_idle_run_days`, `idle_reopen_spells`, then race fields `outcome`, `founder`, `founded_day`, `end_day`, `stage_days`, `rejected_commands`), `sample_years` ([2, 5, 8]), `summary` (spreads; then race lines `seeds_founded`, `seeds_deadline`, `seeds_running`, `wins`, `founded_day`, `founder_stage_day_<n>`, `seeds_playing_at_y<n>`, `seeds_with_rejected_commands`; then contest lines; then spec 008 lines ending with `seeds_with_idled_mine`), `never_day`, `checks` (each with `gated`), `all_gated_passed`. Sweep CSV: one row per seed with opening, listing, unlisted/withdrawn-by-year, first-mine, `world_valid`, per-company `final_cash_<c>`, `mines_built_<c>`, `mines_operating_<c>`, `bankrupt_day_<c>`, then `first_depletion_day`, `depleted_by_y8`, `price_mean_permille_<r>` per resource index, then `outcome,founder,founded_day,end_day`, `stage_<s>_day_<c>` per company and stage, and `rejected_commands`.
- Checks are a `std::vector<Check>` of name/passed/detail/gated. In a sweep a check with `gated == false` is printed but does not affect the exit code. Sweep checks in order (21): `sweepChecks` (`opening_has_mineable_plots`, `unlisted_land_at_year_8`, `median_first_mine_day`, `world_valid`, `ai_commands_valid`), `raceChecks` (`founded_before_deadline`, `win_balance`, `bankruptcies`), `contestChecks` (`seeds_with_bankruptcy`, `mines_leader_over_trailer`, `mean_prices`, `median_mine_life`, `depletion_by_year_8`, `withdrawn_land_at_year_8`), `biteChecks` (`bite_iron`, `bite_copper`, `bite_nickel`, `idled_mines`, `cash_y10`, `bankruptcy_y1_10`, `bankruptcy_y11_20`). Gated: `opening_has_mineable_plots`, `median_first_mine_day`, `world_valid`, `ai_commands_valid`, `founded_before_deadline`, `win_balance`, `bankruptcies`. All the others are reported only (the spec 005-008 goals assumed a 20-year open-ended game).
- Goal thresholds are `constexpr` constants at the top of the sweep section, citing their specs: spec 005 (`kGoalMineableOpening`, `kGoalLandYear`, `kGoalFirstMineDay`), spec 006 (`kGoalBankruptSeedsPer50`, `kGoalMinesRatioPercent`, `kGateMinesRatioPercent`, `kGoalMineLifeMinDays`/`MaxDays`, `kGoalWithdrawnYear8`), spec 010 BR-013 (`kGoalFoundedSeedsPer50` 40, `kGoalMostWinsPer50` 35), spec 008 BR-010 / decision record 003 (`kBiteFirstYear`/`kBiteLastYear`, `kBiteOres`, `kBiteMinPermille`/`MaxPermille`, `kIdledRunDays`, `kGoalIdledSeedsPer50`, `kCashYear`, `kBaselineCashY10`, `kCashY10Divisor`, `kAimPrice*`/`kAimLithium*`). Per-50 goals scale to smaller sweeps rounded up to whole seeds.
- Integer arithmetic throughout the measurements: cents, permille and percent in `int64_t`, sums through `saturatingAdd`, scaling through `sim::checkedMulDiv`; doubles appear only when formatting ratios for output.
- Unmeasured figures are emitted as JSON `null` (blank CSV cell), never zero and never the value of the finished world: a sample year a seed's game did not reach, a summary figure no seed measured. A day that never happened is 0 in the per-seed contest/first-mine fields and `never_day` in spreads and race fields; medians are lower medians so the value is one that occurred.

## Constraints
- Exit codes: 0 success; 1 content failed to load, the CSV could not be opened or written, or stdout failed; 2 usage error; 3 checks failed (single run: only when `--sanity` is given; sweep: any gated check failed, with or without `--sanity`).
- Argument rules: every flag except `--sanity` takes a value; numeric values must be decimal digits only. `--days` 1..`sim::kMaxDay`; `--years` 1..10000 (sets days = years * `sim::kDaysPerYear`; the later of `--days`/`--years` wins); `--ai` 0..16; `--sweep` 1..10000; `--seed` any unsigned 64-bit value. `--sanity` is accepted with `--sweep` and changes nothing. A sweep whose seed range `seed..seed+N-1` would wrap is a usage error. Defaults: seed 1, 20 years, 1 AI rival, no CSV, no sanity, no sweep.
- Without `--sanity` a single run still computes and prints the checks and `all_passed`, but exits 0.
- A run of exactly `deadlineDay` days plays one more tick so the deadline outcome is reached; any other length plays its days and no more. A sweep seed stops when its game ends, so per-seed figures cover only the days that seed played.
- Rejections with `RejectReason::GameEnded` (orders queued behind the founding order) do not count against `ai_commands_valid`.
- A check the run is too short to measure passes as "not evaluated": `economy_alive` needs 2 played years; `median_first_mine_day` needs 250 days; the race checks need `--days` to reach `Content::program.deadlineDay`; the spec 008 checks need 20 years; land, depletion, withdrawn and cash-year-10 goals need a seed still playing at that year; mine life needs a seed that played more than 7 years.
- First-mine figures in a sweep refer to company 0 only. The mine-life cohort is mines that opened at least `kMineLifeCohortDays` (7 years) before the seed's last day; mines closed by bankruptcy before depleting are excluded.
- `jsonString` escapes only `"` and `\`; control characters in names or ids are not escaped.
- In sweep mode the CSV stream is not checked on open, only after the write; the JSON is printed before the CSV is written.
- `DC_DATA_DIR` is an absolute source-tree path fixed at configure time, so a relocated binary needs `--data`.
- No unit tests of its own; it is exercised only through the four CTest command lines. The full 50-seed gated sweep runs only in an optimized, unsanitized build; other builds run a 1- or 2-seed sweep judged by its output.
